Quick Start

Daevon Alpha for Windows  ·  Unreal Engine 5.4.4

This guide covers the fastest path from downloading Daevon to opening it inside Unreal Engine and running your first project analysis.

Alpha notice

Daevon is currently alpha software. Features, compatibility, and interface details may change as development continues.

Requirements

  • Windows
  • Unreal Engine 5.4.4
  • An Unreal Engine project
  • Internet access for license activation and entitlement checks

You do not need to install Python separately — Daevon includes its own local runtime and required dependencies. You also do not need Visual Studio for normal installation or use; the plugin ships with precompiled Windows binaries.

Install Daevon

Daevon has two components:

  • The Unreal Engine plugin, which provides the Daevon interface inside the editor.
  • The Daevon local runtime, which performs project analysis and runs Daevon’s local systems.

Both components must be placed correctly inside your Unreal project.

1. Download Daevon

Download Daevon Alpha v0.1.0 for Windows x64 from the official DaevonAI GitHub release:

Open the release page

Under Assets, download Daevon-Alpha-v0.1.0-Windows-x64.zip. Do not download either of GitHub’s automatically generated Source code archives — those contain repository source files, not the packaged application.

Extract the ZIP before continuing. Inside the package you will find:

Plugins/
Daevon/
LICENSE.txt
THIRD_PARTY_NOTICES.txt
QuickStart.txt

2. Install the Daevon plugin

How you install the plugin depends on whether your project already has a Plugins folder. Open your project’s root folder — the folder containing your .uproject file — and check whether it already contains a folder named Plugins.

If your project does NOT have a Plugins folder: copy the entire Plugins folder from the Daevon package into your project’s root folder. The Daevon plugin will end up in the correct location automatically.

If your project ALREADY has a Plugins folder: do not replace or overwrite it. Instead, copy only the Daevon folder from the package’s Plugins folder into your project’s existing Plugins folder.

Either way, the plugin must end up at YourProject/Plugins/Daevon/:

YourProject/
├─ Plugins/
│  └─ Daevon/
└─ YourProject.uproject
Check the folder path

If you accidentally end up with YourProject/Plugins/Plugins/Daevon/, move the Daevon folder up one level so it sits directly inside your project’s Plugins folder.

3. Install the Daevon runtime

Return to the downloaded package. Copy the separate Daevon runtime folder — the one containing Daevon.exe — into the root of your Unreal project, next to your .uproject file. When finished, Daevon.exe must be at YourProject/Daevon/Daevon.exe.

YourProject/
├─ Daevon/
│  ├─ Daevon.exe
│  └─ _internal/
│
├─ Plugins/
│  └─ Daevon/
│
└─ YourProject.uproject
Runtime location matters

The plugin looks specifically for YourProject/Daevon/Daevon.exe. If the runtime is placed elsewhere, Daevon will not be able to start it.

4. Open your Unreal project

Open your project using Unreal Engine 5.4.4. Unreal may show a notice that a new plugin is available. You should not be asked to compile or rebuild Daevon — the alpha plugin ships with precompiled Windows binaries.

5. Enable Daevon

If the plugin isn’t already enabled: open Edit → Plugins, search for Daevon, make sure it’s enabled, and restart Unreal Engine if prompted.

Launch Daevon

Daevon currently launches from an Editor Utility Widget included with the plugin.

6. Show plugin content

In Unreal Engine, open the Content Browser, open its Settings (or filter) menu, and enable Show Plugin Content. Plugin content is hidden by default, so the Daevon interface won’t appear in the Content Browser until this is enabled.

7. Find the Daevon interface

In the Content Browser’s sources panel, navigate to Daevon Content → Editor and locate EUW_Daevon — the Editor Utility Widget used to open Daevon.

8. Open Daevon

Right-click EUW_Daevon and choose Run Utility Widget. The Daevon window opens, with Chat, Refresh Daevon, Analyze Project, connection status, and license status. You can dock it anywhere; if you close it, run the widget again to reopen.

Windows SmartScreen notice

The first time Daevon’s local runtime starts, Windows may display “Windows protected your PC.” Daevon is a new alpha release and may not yet have an established SmartScreen reputation. If you downloaded Daevon from the official DaevonAI release linked above, continue by selecting More info → Run anyway. This warning does not necessarily mean Windows detected malware; it can appear for newly released applications. Do not disable Windows Security or SmartScreen to run Daevon — and if your copy came from anywhere other than the official DaevonAI release page, do not run it.

Use Daevon

1. Connect to Daevon

Before activating a license or running analysis, Daevon’s local runtime must be running — you do not need to launch Daevon.exe manually. To connect, either send a message through Daevon chat or click Refresh Daevon in the upper-left of the panel. Daevon starts its runtime automatically; when ready, the status shows Connected.

Important

Connect to Daevon before attempting license activation. If the local runtime isn’t running, activation cannot complete — Daevon isn’t yet available locally to process the request.

2. Activate your license

Activation is only required for paid features. Once Daevon shows Connected, open the dropdown in the upper-left, open the license activation screen, enter the activation token from your purchase, submit it, and wait for confirmation.

Your token begins with sub_v1_ and is shown after purchase and emailed to you. Keep it private — it’s a credential, like a password. During the alpha, activation is tied to one machine; to move Daevon to another machine, contact support.

Using Daevon without activation: you don’t need a token for the free features. With an inactive license you can chat, analyze your project, and view your Project Health score. An active license unlocks the detailed findings behind that score.

3. Analyze your project

Click Analyze Project near the top of the panel. Daevon scans the current project, builds a structural dependency graph, and evaluates supported relationships and architectural concerns. Daevon does not modify your project — it analyzes, reports, and explains, leaving changes under your control.

Project Health is available without a subscription — a high-level view of the project’s structural health. Findings (the specific issues behind the score) require an active license.

Next

Once Daevon shows Connected and your first analysis completes, setup is done. For a deeper explanation of Project Health, Findings, the analysis rules, commands, and the Project Knowledge Core, continue to How to Use Daevon.

Getting help

If you lose your activation token, use the token-resend option or contact contact.daevonai@gmail.com. Daevon is alpha software providing AI-assisted development guidance — you remain responsible for project decisions and changes. Keep your project backed up and use version control when possible.

Known alpha limitations

  • Connect to Daevon before attempting license activation.
  • Chat may occasionally display additional internal text.
  • The chat input may occasionally lose cursor focus after sending a message.

These known interface issues do not prevent project analysis from running.
